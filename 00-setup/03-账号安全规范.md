# 账号与信息安全规范

> 海外获客账号是你的生产资料。封一个号，损失的不只是账号，是里面几百条已建立的 KOL 对话关系。

## 一、绝对不做的事

| ❌ 不要 | 为什么 |
|---|---|
| 用工具批量群发私信 | X / Instagram / TikTok 都有行为检测，批量发送模式会被判定为垃圾信息，轻则限流重则封号 |
| 用爬虫抓取平台数据 | 违反各平台 ToS。IP 和账号会一起被标记 |
| 多个工作账号在同一浏览器窗口反复切换登录 | 平台通过 Cookie 和设备指纹关联账号，一个被封可能牵连全部。用 Chrome 多 Profile 隔离 |
| 把密码、Token、Cookie 写进任何文档或发给 AI | 一旦进了文件或对话记录，就等于泄露 |
| 新账号第一天就开始大量发私信 | 账号需要「养」：先发内容、先互动，一周后再开始外联 |
| 在 Discord 社区直接发广告 | 会被管理员直接踢，且很多 VR 社区管理员之间互通 |

## 二、私信节奏参考（保守值，宁慢不封）

| 账号年龄 | 每天私信上限 | 备注 |
|---|---|---|
| 第 1 周 | **0** | 只发内容、只互动、只观察 |
| 第 2-3 周 | 每天 10-15 条 | 分散在全天，不要一小时内发完 |
| 1 个月后 | 每天 20-30 条 | 有正常回复和互动的账号可以逐步提高 |

- 私信之间**留间隔**，不要连着发。
- **先互动再私信**：关注他、点赞他两条近期内容、评论一条有内容的评论，隔一天再 DM。回复率会明显高于直接冷 DM。
- YouTube 优先走**简介里的商务邮箱**，不要走 YouTube 站内私信（很多人根本不看）。

## 三、凭据管理

- 所有密码进**密码管理器**（Mac 自带「密码」App 或 1Password / Bitwarden）
- 所有平台开 **2FA**，优先用验证器 App，其次短信
- 2FA **恢复码**打印出来放抽屉，或存进密码管理器的备注里
- `00-setup/账号清单.md` 里**只记**：平台名 / 用户名 / 注册邮箱。不记密码，不记 2FA 码

## 四、KOL 隐私（欧洲：受 GDPR 管，不是自愿规范）

仓库里**只存公开信息**：

| ✅ 可以存 | ❌ 不要存 |
|---|---|
| 公开主页链接、用户名 | 私人手机号 |
| 主页上公开的商务邮箱 | 家庭地址（寄样地址存在公司物流系统，不进仓库） |
| 公开的粉丝数、播放量 | 身份证件、护照 |
| 他自己报的价格 | 银行账号、PayPal 账号 |

寄样需要的收件信息，走公司正式的订单/物流系统，不要抄一份到这个仓库里。

**GDPR 下还要做到两件事**（存欧盟居民数据受法律管）：

- **达人说「别再联系我」→ 立刻把状态改成「已拒绝-勿再联系」**，之后不得再排进跟进队列。`/daily` 会自动跳过这些人。
- **超过 24 个月没有任何业务往来的联系人，清理或匿名化**（删掉邮箱，只留账号名和结论）。每季度做一次。

不要用第三方工具去"挖"未公开的私人邮箱——主页 bio 里公开的商务邮箱可以用，挖出来的在欧盟风险很高。
具体的合法依据和保留期限，让公司法务给一个明确口径。

## 五、内容合规（保护自己也保护 KOL）

- 付费或寄样的合作内容**必须标注广告关系**，而且**主打欧洲要用当地语言**：
  德/奥 `Werbung` 或 `Anzeige`、法 `Publicité` 或 `Collaboration commerciale`、意 `Pubblicità`、
  西 `Publicidad`、荷/比 `Advertentie`、波 `Reklama`、英 `#ad`。
  **只写 `#ad` 在德国、法国不够。** 标注要在开头数秒内可见，**并且同时**打开平台自带的付费推广开关
  （TikTok Branded Content / YouTube Paid Promotion）。
  欧洲多国有真实执法，罚的是品牌方和达人双方。详见 `00-setup/06-欧洲市场作战要点.md` 第四节。
- 产品宣传**不要做医疗或健康效果承诺**（VR 设备尤其要注意，不要说「治疗晕动症」「保护视力」这类话）。
- 参数和对比数据要有依据，不要让 KOL 替你说没验证过的数字。
- 给 KOL 的 brief 里就把「必须标注」和「不能说什么」写清楚，别等出事再说。
